## venue 双重展开的根因（17:0x，用户追问「是不是 VenueNorm.py」）

是。`markdown_generator/VenueNorm.py` 的守卫 `standard_format_regex = r"\([A-Z]{2,10}\)"` 只认纯字母缩写，`(ACM MM)` / `(ACM WWW)` 带空格 → 守卫不命中 → 往下走 `venue_pattern`；该正则的负向前瞻 `(?!\s*\()` 只挡紧跟 `(` 的情况，括号里那个短 key `ACM MM` 后面跟 `)` 就放行，于是整段替换成全名，形成 `… (ACM International Conference on Multimedia (ACM MM))`。一次 pass 就够产生「双重」，不是跑了两遍。

修法：`standard_format_regex` 放宽到允许空格与数字，且新增 `is_normalized()`，只有括号里的 token 命中 `full_mapping` 才跳过。101 条 bib booktitle/journal 全部验证不再二次展开，且 `normalize_venue` 幂等。
